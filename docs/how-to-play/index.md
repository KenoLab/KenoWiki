# Getting started

## On our website

### 1. Create your account

Log in on [www.kenolab.eu](https://www.kenolab.eu) with your **Discord** account. It's the only
login method.

![Kenolab login page with the Connect with Discord button](/images/how-to-play/create-account.png)

### 2. Register for an event

Pick an event and register for it. The event's labs become visible when it starts.

![Events page listing upcoming events](/images/how-to-play/register-event.png)

### 3. Join the Discord

Join the [Kenolab Discord server](https://discord.gg/cXaKPSzgUE) to get event announcements,
ask for help and use [Kenobot](/kenobot/).

![Discord invitation to the Kenolab server](/images/how-to-play/join-discord.png)

## With Kenobot

### 4. Claim your access

Run `/access` to check and claim your access to the platform and the event.

![Kenobot reply to the /access command](/images/how-to-play/access.png)

### 5. Join or create a team

Run `/team` to create a team or join an existing one using its secret code.

![The /team command in Discord](/images/how-to-play/team.png)

### 6. Get connected

Run `/vpn` and Kenobot sends you your VPN configuration file, see [VPN Usage](/vpn/).

![Kenobot reply to the /vpn command with the configuration file](/images/how-to-play/vpn.png)

### 7. Deploy a lab and hunt flags

Start your lab instance with `/play`, attack the machines, and submit every flag you find with
`/flag`.

::: tip Locked labs
Some labs depend on others. Submit all flags of the prerequisite labs to unlock them.
:::

::: warning
A flag can only be submitted once per player.
:::
