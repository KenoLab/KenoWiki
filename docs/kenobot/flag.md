# /flag

Submit a flag you found in a lab.

```text
/flag flag:<your flag>
```

You must have access to the event and be in a team. See [Flag strategy](/how-to-play/flag) to know where flags are and what they look like.

## Possible replies

| Reply | Meaning |
|---|---|
| Flag owned | The flag is valid. The points are added to your score. |
| First blood | You are the first player to submit this flag. |
| New lab(s) unlocked | You completed a prerequisite lab, new labs are now available in [`/play`](/kenobot/event-only/play). |
| Flag not valid | The flag is wrong. Check for typos and extra spaces. |
| Already submitted | You already submitted this flag. |

::: warning
A flag can only be submitted once per player.
:::
