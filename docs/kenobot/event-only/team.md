# /team

View, create, join or leave your event team.

```text
/team
```

Only works while an event is running on the server. You must have access to the event, see [`/access`](/kenobot/access).

::: info
Solo event? You do not need this command, your team is created for you.
:::

## Without a team

| Button | What it does |
|---|---|
| Create Event Team | Create a new team with a name and a description. You become its leader. |
| Join Event Team | Pick a team and enter the secret code its leader gave you. |

## As a team member

| Button | What it does |
|---|---|
| Leave Event Team | Leave your team. |

## As a team leader

| Button | What it does |
|---|---|
| Modify Event Team | Change the team name and description. |
| Kick Member | Remove a player from the team. |
| Delete Event Team | Delete the team. |

::: tip
You can only be in one team per event.
:::
