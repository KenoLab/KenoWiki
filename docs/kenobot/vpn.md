# /vpn

Receive your VPN configuration file.

```text
/vpn
```

You must have access to the event and be in a team. Kenobot sends you a `.ovpn` file, only visible to you.

![Kenobot reply to the /vpn command with the configuration file](/images/how-to-play/vpn.png)

To connect with it, see [VPN Usage](/vpn/).

::: warning
Your VPN file is personal. Do not share it.
:::

If Kenobot says no VPN configuration was found, [contact us](/introduction/support).
